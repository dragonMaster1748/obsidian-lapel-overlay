# Lapel Overlay

**Lapel Overlay** is a modified fork of [Lapel by Liam Cain](https://github.com/liamcain/obsidian-lapel) that changes how heading-level indicators are displayed in Obsidian.

## What's Different

Lapel normally displays its `H1`–`H6` indicators in a dedicated editor gutter. **Lapel Overlay removes that dedicated column and displays the indicators as an overlay beside each heading instead.**

This keeps the heading level visible without reserving extra horizontal space throughout the document.

The heading indicators remain clickable, allowing the heading level to be changed directly from the marker.
